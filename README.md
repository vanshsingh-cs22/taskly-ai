# 🚀 Taskly AI - Premium Team Task Manager

Taskly AI is a production-grade, full-stack collaborative platform designed for modern teams. It features real-time synchronization, role-based access control, and a sleek, high-performance user interface.

![Dashboard Preview](https://via.placeholder.com/1200x600?text=Taskly+AI+Premium+Dashboard)

## ✨ Key Features

### 🏢 Dual-Portal System
- **Admin Portal**: Complete team management, project oversight, and global task assignment.
- **Member Portal**: Personalized dashboard focusing on assigned tasks, individual productivity stats, and real-time activity.

### ⚡ Real-Time Collaboration
- **WebSockets (Socket.io)**: Instant task updates and status changes across all users.
- **Dynamic Kanban**: Drag-and-drop task management with persistent state.

### 🎨 Premium UI/UX
- **Modern Aesthetics**: Sleek dark mode, glassmorphism, and smooth Framer Motion animations.
- **Responsive Design**: Fully optimized for desktops and mobile browsers.

### 🤖 AI-Ready Foundation
- **AI Assistant**: Dedicated module for future AI-driven team collaboration.
- **Productivity Analytics**: AI-generated performance scoring for team members.

---

## 🛠️ Tech Stack

- **Frontend**: Next.js 15 (App Router), React, Tailwind CSS, Framer Motion, Lucide Icons, Axios.
- **Backend**: Node.js, Express, Socket.io, TypeScript.
- **State Management**: Zustand & React Hooks.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/vanshsingh-cs22/taskly-ai.git
cd taskly-ai
```

### 2. Install Dependencies
```bash
# Frontend
cd frontend
npm install

# Backend
cd ../backend
npm install
```

### 3. Run Locally
```bash
# Start Backend (Port 8081)
cd backend
npm run dev

# Start Frontend (Port 3000)
cd frontend
npm run dev
```
